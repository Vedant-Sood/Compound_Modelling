# Chemical Modelling

A local-first computational chemistry and materials science workstation: quantum-mechanical
electron clouds, molecules, crystals, alloys and compound discovery, built on established
scientific libraries (PySCF, ASE, spglib, RDKit, pymatgen data) with a React + Three.js
GPU-rendered interface.

**Status: Phase 1 (Atomic Explorer) and Phase 2 (Molecular Builder) are implemented and validated.** Later phases
are tracked in [docs/ROADMAP.md](docs/ROADMAP.md). Work split for parallel agents is in
[docs/HANDOFF.md](docs/HANDOFF.md).

## What works now (Atomic Explorer)

- Interactive periodic table (Z = 1–118) with properties that carry their source and method;
  missing data is shown as *unavailable*, never filled in.
- Charge and isotope selection; ion configurations (tabulated where available, rule-based
  otherwise, and labelled as such); protons/neutrons/electrons; valence electrons; Slater Z_eff.
- **Exact analytic hydrogen-like orbitals** (any n ≤ 8, s/p/d/f/…), real or complex basis,
  reduced-mass correction from the chosen isotope.
- **Genuine many-electron calculations** with PySCF (HF, DFT: LDA/PBE/B3LYP/PBE0/ωB97X-D;
  STO-3G … def2-TZVP, ECPs for heavy elements) run as cancellable, cached background jobs:
  total and spin density, any canonical orbital, electrostatic potential mapped on a density
  surface, orbital energies, ⟨S²⟩, convergence history.
- GPU ray-marched volumetric rendering and isosurfaces defined by **enclosed probability**,
  amplitude sign / complex phase colouring, clipping planes, cross-sections with distance and
  angle measurement, perspective/orthographic cameras.
- Physical coordinates in pm throughout; dynamic scale bar from fm to µm; the nucleus is drawn at
  its estimated true size and the UI states the magnification whenever it is enlarged.
- Plots with units and CSV/PNG export (radial distribution, energy levels, SCF convergence);
  image export, Gaussian CUBE export, project save/open, undo/redo, autosave, keyboard shortcuts.

## Molecular Builder

- Build in 3D: add atoms bonded at covalent-radius distances, delete atoms, create bonds and
  cycle bond orders, add hydrogens (RDKit), perceive bonds from geometry, load examples or SMILES
  (RDKit ETKDGv3 + MMFF94 starting geometry, labelled as force-field quality).
- Neutral molecules, ions and radicals (charge and multiplicity checked against the electron count).
- Fast mode: MMFF94/UFF clean-up. Accurate mode: PySCF HF/DFT single points, geometry
  optimisation (analytic gradients + ASE BFGS) and rigid bond scans, as background jobs.
  Balanced mode (optional `tblite`): GFN2-xTB / GFN1-xTB single points and optimisations with
  xTB charges, dipole and gap, for larger molecules (no density volumes).
- Distance, angle and dihedral measurement; formula, molar mass, Mulliken charges, dipole,
  HOMO–LUMO gap; MO energy diagram with click-to-view orbitals; density, spin density and ESP
  rendered around the ball-and-stick model; optimisation and scan plots; configuration comparison
  (ΔE only between same formula and method); XYZ/JSON save and open.

## Quick start

### Linux / WSL2

```bash
cd frontend && npm ci && npm run build && cd ..
./scripts/start-backend.sh        # serves API + UI at http://localhost:8000
```

Development mode with hot reload: run `uvicorn chemmodel.api.main:app --reload` in `backend/`
and `npm run dev` in `frontend/` (http://localhost:5173, proxies `/api`).

### Windows 11

PySCF does not ship Windows wheels, so the backend runs inside WSL2 Ubuntu. From PowerShell:

```powershell
.\scripts\start-windows.ps1
```

## Tests

```bash
cd backend && python -m pytest        # 117 scientific validation tests
cd frontend && npm test && npm run typecheck
```
