# Roadmap and status

| Phase | Scope | Status |
|---|---|---|
| 1 Atomic foundation | frontend shell, periodic table, atomic data, electron-cloud renderer, measurement, basic quantum calculations | **done** (see README) |
| 2 Molecular modelling | builder, bonding, geometry optimisation, MOs, densities | **done** (xTB balanced mode via optional tblite) |
| 3 Crystals and materials | unit cells, symmetry, supercells, defects, NaCl/Cu/diamond/Si/Fe/graphite | open (workstream B) |
| 3 Data I/O + databases | XYZ/CIF/PDB/MOL/SDF/POSCAR/CUBE import-export, Materials Project, PubChem, OPTIMADE with offline cache | open (workstream C) |
| 4 Alloys and compound discovery | composition tools, SQS, phase/convex-hull analysis | after B and C |
| 5 Advanced simulation | MD (ASE), parameter sweeps, property calculations | later |
| 6 Optimisation and packaging | CI, installer, performance | open (workstream D) |
